## Cinnections

Cinnections is a movie trivia game based off of the NYT's 'Connections' game. In this game, players are presented with 16 movies (represented using their posters) and tasked with grouping these movies into 4 groups of 4, each group sharing one common category/theme. Like the NYT's Connections, the categories range from green (easiest) to red (hardest). These categories can range from actors and directors to genres and shared themes. 

This game was built using React/CSS and deployed through CloudFlare. You can play it at https://cinnections.pages.dev/!
